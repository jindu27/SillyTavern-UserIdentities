# 用户身份 · Narrative Identities

给 SillyTavern 群聊和私线扩展提供剧情驱动的用户身份。

这个扩展不要求手动创建身份。发送类似下面的剧情后，模型会先判断是否要创建身份，确认弹窗通过后才建立并切换身份。

```text
我创建了一个小号，名字叫林澈，用它去联系团子。
```

在身份揭露前，团子会把“你”和“林澈”当成两个人，各自保存关系状态和私线记忆。创建身份和揭露身份需要确认，切换到已经存在的身份会直接生效。发送下面的剧情可以切回本号或揭露身份。

```text
我切回本号。
我告诉团子，林澈其实就是我。
```

安装后与 `多线群聊 · Private Routes` 1.4.0 或更高版本配合使用。没有多线扩展时，身份状态仍会保存在当前聊天中，供其他兼容扩展读取。
